# MediCare AI – Smart Healthcare App

MediCare AI is a modern healthcare application designed to help users manage their healthcare needs through a simple and user-friendly interface.

## Features

- 🔐 User Login & Sign Up
- 🤖 AI Health Assistant
- 👨‍⚕️ Find Doctors
- 📅 Book Appointments
- 📋 Medical Reports
- 👤 User Profile
- ⚙️ Settings
- 🔔 Notifications
- 🔒 Privacy & Security
- 🚪 Logout

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Figma
- Git & GitHub

## AI Assistant

The AI Health Assistant provides basic health-related guidance for common concerns such as:

- Headache
- Fever
- Cold & Cough
- Stomach discomfort
- Sleep problems
- Stress
- Medicine-related questions

> Note: This AI assistant is a front-end demonstration and does not replace professional medical advice.
